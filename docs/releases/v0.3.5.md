# RustFlexstack v0.3.5 — Multi-Platform V2X CLI & C-V2X Telematics Support

This release introduces official multi-firmware support for **Qualcomm Telematics C-V2X Direct Radio (PC5 Mode 4)** alongside **ETSI TS 103 097 / 102 941 GeoNetworking** on generic Linux and Cohda Wireless Mk6/MK6C hardware.

---

## Quick Installation (Recommended)

Like `rustup`, you can install the V2X FlexStack CLI directly in your terminal using a single command. The installer automatically detects your operating system, CPU architecture, and onboard Qualcomm C-V2X firmware flavour.

### Using `curl` (Linux x86_64, generic AArch64):
```bash
curl --proto '=https' --tlsv1.2 -sSf https://raw.githubusercontent.com/Fundacio-i2CAT/RustFlexstack/master/install_v2x_flexstack_cli.sh | sh
```

### Using `wget` (Cohda Mk6 / MK6C OBU & RSU):
```bash
wget -qO- https://raw.githubusercontent.com/Fundacio-i2CAT/RustFlexstack/master/install_v2x_flexstack_cli.sh | sh
```

> **What the script does automatically:**
> 1. Detects platform (`x86_64` vs `aarch64`).
> 2. On Cohda hardware, inspects `libtelux_cv2x.so` and automatically pulls both `v2x_cli_cohda` and the exact matching C-V2X binary (`v2x_cli_cv2x-mk6-fw20`, `v2x_cli_cv2x-mk6-fw19`, or `v2x_cli_cv2x-mk6c`).
> 3. On generic Linux PCs, pulls `v2x_cli_x86` or `v2x_cli_aarch64`.
> 4. Installs executables into `/usr/local/bin` (`v2x_cli` and `v2x_cli_cv2x`) and performs an automated self-test.

## What's Changed

### 1. Multi-Firmware Qualcomm Telematics FFI Compatibility
- Added automated compile-time detection in `build.rs` and `cv2x_wrapper.cpp` to resolve symbol collisions across Qualcomm Telematics SDK versions:
  - Supports modern Firmware 20 (`telux::cv2x::Cv2xFactoryImpl::getCv2xRadioManager`).
  - Supports Firmware 19 (`telux::cv2x::Cv2xFactory::getCv2xRadioManager`).
  - Supports legacy MDM9150 / MK6C SDKs (`telux::cv2x::Cv2xRadio`).
- Eliminates runtime `undefined symbol` dynamic linker crashes on Cohda Mk6 units.

### 2. Standalone Generic Linux Builds
- Standard `v2x_cli_x86` and `v2x_cli_aarch64` are now built cleanly with standard Rust toolchain without dependencies on Cohda proprietary toolchains.
- Full ETSI TS 103 097 v1.4.1 security verification, PKI enrollment (TS 102 941), GeoNetworking, CAM, and DENM simulation over Ethernet or Wi-Fi.

### 3. Universal One-Line Installer
- Added `install_v2x_flexstack_cli.sh` supporting both GitHub releases and air-gapped lab mirrors (`--mirror <URL>`).
- Auto-detects hardware and sets up permissions seamlessly.

## Basic Usage

### Running on Standard Linux (x86_64 / AArch64 / Cohda Raw Socket):
```bash
# Display help and available options
v2x_cli --help

# Transmit signed CAMs over network interface
v2x_cli tx --interface eth0 --station-id 101 --frequency 10

# Receive and verify CAMs with PKI trust store
v2x_cli rx --interface eth0 --trust-store /path/to/truststore.json
```

### Running C-V2X Direct Radio on Cohda Mk6 / MK6C:
```bash
# Display C-V2X options
v2x_cli_cv2x --help

# Start C-V2X PC5 Mode 4 Station (CAM transmission on ITS band)
v2x_cli_cv2x tx --station-id 42 --port 2000

# Listen and verify C-V2X PC5 Mode 4 packets
v2x_cli_cv2x rx --port 2000
```
